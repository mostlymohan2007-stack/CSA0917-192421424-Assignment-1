CAMPUS SMART-PARKING SYSTEM – JAVA SOURCE CODE

Files:
1. CampusSmartParkingSystem.java
   Complete menu-driven console application. It supports user registration,
   monthly / one-day pass selection, vehicle entry and exit, slot allocation,
   ticket generation, availability display and fee calculation.

2. ParkingFacility.java
   Standalone completed Task 3 program. It demonstrates jagged-array slot
   allocation and release. Its expected output matches the assignment PPT.

3. FeeDemo.java
   Standalone completed Vehicle / Chargeable demonstration for Tasks 6–9.
   Its expected output matches the assignment PPT.

REQUIREMENT:
JDK 17 or later is recommended because the source uses modern Java syntax
(switch expressions and pattern matching for instanceof).

RUN THE COMPLETE APPLICATION:
javac CampusSmartParkingSystem.java
java CampusSmartParkingSystem

RUN TASK 3:
javac ParkingFacility.java
java ParkingFacility

RUN TASKS 6–9:
javac FeeDemo.java
java FeeDemo

NOTE:
The complete application is an academic console prototype. It stores data
in memory only. It does not use a database, web API, real payment gateway,
or persistent storage. The sample hourly rates and charging fee are
demonstration values and should be confirmed with your faculty.
